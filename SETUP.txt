To repeat the successful Python connection check, run from this project:

Python BLPAPI bundles its native library; no separate C++ compiler is required
for the Python wheel. Pip may need internet access for any dependencies.

After an approved MSVC C++ installation, open an x64 Native Tools Command
Prompt and change to this project directory. Compile:
cl /EHsc /I"vendor\blpapi_cpp_3.26.9.1\include" check_bloomberg.cpp "vendor\blpapi_cpp_3.26.9.1\lib\blpapi3_64.lib" /Fe:check_bloomberg.exe

In that same command prompt, add the SDK runtime directory for that session:
set "PATH=%CD%\vendor\blpapi_cpp_3.26.9.1\bin;%PATH%"
check_bloomberg.exe

Keep Bloomberg Terminal open and signed in. A successful connection-only
check does not establish entitlements for any particular security or field.
